# MindBinder — Support

MindBinder is a notes and writing app for Mac, iPhone and iPad: rich notes
with tags, to-do lists with reminders, iCloud sync, home-screen widgets,
export to PDF, ePub, Word and Markdown — plus full book projects with
chapters, characters and world-building for when a note grows into a story.

## Frequently asked questions

**Where is my writing stored?**
Locally on your device. With iCloud Sync enabled, it also lives in your own
iCloud Drive so your Mac, iPhone and iPad stay in sync. The developer never
has access to your writing.

**How do I enable sync?**
Settings → Sync → enable iCloud Sync on each device, signed in to the same
Apple ID.

**How do I export my book?**
Open a project and use the export action to create PDF, ePub, Word (.docx),
HTML or Markdown files.

**I lost data — can I get it back?**
The app keeps automatic local backups. Go to Settings → Backups to restore a
recent snapshot.

**How does the AI assistant work?**
It is optional and off by default. Connect your own Anthropic API key in
Settings to enable it; selected text is then sent directly to Anthropic only
when you use the assistant.
